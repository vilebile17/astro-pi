# Astro PI

## Our submission for the **Mission Space Lab** competition

## Cloning instructions

> [!NOTE]
> If you aren't familiar with git, check out [this course](https://www.boot.dev/courses/learn-git)

**Firstly,** fork the repo on Github through the button on the top of this repo.

Once you've got it forked, clone it to your local machine with

```bash
git clone https://github.com/USERNAME/astro-pi
```

> [!NOTE]
> Don't forget to replace `USERNAME` with your actual username!

Then you can make the code changes that you with to do and commit it to your Github fork.

**Finally,** create a pull request by opening your Github fork in your browser and
clicking on the **Contribute** button towards the top of the page followed by
**Open Pull Request.** After this add a description of what you did, click send,
and then I'll get a notification to review the work you did :)
